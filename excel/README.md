# Excel what-if model

`learning-whatif-model.xlsx` — a formula-driven planning model (no hardcoded results)
that projects completions and ROI under two levers: the **mastery-gate pass rate** and
an **engagement-programme uplift**. Inputs are blue, key levers are highlighted yellow,
calculated cells are grey; a sensitivity table sweeps the target gate pass rate.

Baseline figures are sourced from the analysis (see cell notes). All figures are
planning estimates — read alongside `WRITEUP.md`, which cautions that the unadjusted
gate gap overstates the gate's causal effect.
