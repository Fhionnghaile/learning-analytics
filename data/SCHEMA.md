# Data schema & anonymisation

The dataset is **synthetic**, generated by `data/generate_raw.py`, standing in for
anonymised Derry platform data with the same shape and no real people.

## Anonymisation
- `student_id` is a **salted SHA-256 hash** truncated to 12 hex chars (`stu_xxxxxxxxxxxx`).
  There is no reverse map in the repo; the salt is a constant in the generator only.
- **No PII fields exist** — no names, emails, phones, addresses, or dates of birth.
  `pipeline.assert_no_pii()` enforces this and fails the build if a PII-shaped column
  or an un-hashed id appears.

## Tables (raw, `data/raw/`)

### students.csv — one row per student
| column | type | notes |
|---|---|---|
| `student_id` | str | pseudonymous key |
| `cohort` | str | enrolment cohort (`2025-spring` …) |
| `prior_score` | float | prior-ability proxy, 0–100 (the key confounder) |

### enrollments.csv — one row per (student, course)
| column | type | notes |
|---|---|---|
| `enrollment_id` | int | unique |
| `student_id` | str | FK → students |
| `course`, `cohort` | str | |
| `sessions`, `active_minutes` | int | engagement |
| `mastery_gate_passed` | 0/1 | passed the course's mastery gate |
| `completed` | 0/1 | **target** |
| `weeks_to_complete` | float | present iff `completed=1` |

### events.csv — one row per (enrollment, active week)
| column | type | notes |
|---|---|---|
| `enrollment_id` | int | FK → enrollments |
| `week` | int | 1-based |
| `minutes` | int | active minutes that week (drives the retention curve) |
